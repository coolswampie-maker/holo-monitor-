# Аудит зависимостей под Windows x64

Проверено скачиванием колёс под целевую платформу с macOS:

```
pip download -r requirements/requirements-lock.txt \
    --only-binary=:all: --platform win_amd64 \
    --python-version 311 --implementation cp
```

Целевая среда: **Python 3.11 x64, Windows 10/11**.

## Прикладные зависимости

| пакет | версия | колесо win_amd64 | компилятор | примечание |
|---|---|---|---|---|
| numpy | 2.4.6 | есть | не нужен | несёт свои OpenBLAS и `msvcp140.dll` |
| scipy | 1.17.1 | есть | не нужен | несёт свои OpenBLAS |
| scikit-image | 0.26.0 | есть | не нужен | |
| scikit-learn | 1.9.1 | есть | не нужен | несёт `msvcp140.dll`, `vcomp140.dll` |
| matplotlib | 3.11.2 | есть | не нужен | шрифт DejaVu Sans в комплекте, кириллица |
| tifffile | 2026.3.3 | есть (чистый Python) | не нужен | |
| Pillow | 12.3.0 | есть | не нужен | |
| joblib | 1.6.0 | есть (чистый Python) | не нужен | |

Косвенные: contourpy, cycler, fonttools, imageio, kiwisolver, lazy-loader,
narwhals, networkx, packaging, pyparsing, python-dateutil, six,
threadpoolctl, cloudpickle — все с колёсами под win_amd64.

## Итог

- **Visual Studio не требуется.** Все 22 пакета ставятся из готовых колёс.
- **CUDA не требуется.** Расчёт идёт на процессоре.
- **Пакетов только для macOS нет.**
- **PyTorch, TensorFlow и прочих сред обучения в поставке нет.** Модели —
  случайный лес и градиентный бустинг из scikit-learn, суммарно 4 МБ.
  Обучение в runtime не нужно, только предсказание.
- **Единственное, что должно быть в системе** — распространяемые
  компоненты Microsoft Visual C++ 2015–2022 x64. На Windows 10/11 они
  почти всегда уже установлены; numpy и scikit-learn к тому же несут
  свои копии нужных библиотек.

## Ожидаемый размер

| часть | размер |
|---|---|
| Python 3.11 встраиваемый | 21 МБ |
| Библиотеки | 227 МБ |
| Модели | 4 МБ |
| Код и интерфейс | менее 1 МБ |
| Демонстрационные данные (8 кадров) | 34 МБ |
| **Итого папка** | **около 290 МБ** |
| Архив для переноса | около 150 МБ |

Полный набор из 56 кадров (272 МБ) в поставку не входит: для
демонстрации достаточно восьми.

## NOT TESTED

Всё перечисленное проверено **скачиванием колёс и разбором их состава
на macOS**. Установка и запуск на настоящей Windows не выполнялись.
