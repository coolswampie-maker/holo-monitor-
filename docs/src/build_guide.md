# Что это за документ

Инструкция по сборке автономной версии ГОЛОЦИТа на чистой машине
с Windows. Написана так, чтобы её можно было выполнить, не разбираясь
в устройстве проекта.

Всё, что описано ниже, на Windows **не выполнялось**: подготовка
велась на macOS. Поэтому документ содержит и раздел о том, что делать,
если что-то пойдёт не так.

# Что нужно один раз установить

**Python 3.11 x64.** Именно 3.11 — на нём зафиксированы версии всех
зависимостей и обучены модели. Другая версия не подойдёт: формат
файлов моделей несовместим между версиями scikit-learn.

Скачать: `https://www.python.org/downloads/release/python-3119/`
Выбрать **Windows installer (64-bit)**.

При установке обязательно отметить галочку **«Add python.exe to PATH»**.

Больше ничего ставить не требуется. Visual Studio не нужна: все
зависимости ставятся из готовых сборок.

# Сборка

1. Скопируйте папку `HOLOCYT_WINDOWS_TRANSFER` на диск. Путь может
   содержать русские буквы и пробелы.
2. Откройте папку.
3. Двойным щелчком запустите `build\BUILD_WINDOWS.bat`.
4. Ждите. Первый запуск занимает 10–20 минут: скачиваются зависимости.
5. По окончании появится папка `dist` с готовым приложением.

Скрипт делает всё сам: проверяет версию Python, создаёт изолированную
среду `.venv-build`, ставит зависимости точных версий, удаляет прежнюю
сборку, запускает PyInstaller, переименовывает результат, копирует
документацию и проверяет, что собранное приложение запускается.

В систему ничего не устанавливается, кроме самого Python.

# Проверка

1. Запустите `diagnostics\SELF_CHECK_WINDOWS.bat`.
   Ожидаемый результат — **15 / 15 PASS**.
2. Откройте папку `dist` и запустите приложение.
3. Нажмите «Открыть демонстрационный эксперимент».
4. Нажмите «Анализировать». Восемь кадров считаются около 20 секунд.
5. Нажмите «Экспорт CSV» и «Сформировать PDF».
6. Проверьте, что файлы появились в папке `out`.

Затем пройдите список `WINDOWS_ACCEPTANCE.md` и отметьте, что
сработало, а что нет.

# Если сборка не удалась

### Python не найден

Скрипт напишет об этом прямо. Установите Python 3.11 x64 и не забудьте
галочку «Add python.exe to PATH». Проверить: откройте командную строку
и наберите `py -3.11 --version`.

### Найдена не та версия Python

Поставьте 3.11 рядом с имеющейся — они не конфликтуют. Скрипт ищет
именно через `py -3.11`.

### Не скачиваются зависимости

Нужен доступ в Интернет **на время сборки** (готовому приложению сеть
не нужна). Если сеть за прокси-сервером, настройте переменные
`HTTP_PROXY` и `HTTPS_PROXY` перед запуском.

### PyInstaller отработал, но приложение не запускается

Это разделяет два разных типа проблем. Запустите
`build\RUN_WINDOWS_SOURCE.bat` — программа стартует из исходников,
минуя упаковку.

- **Из исходников работает, собранное — нет.** Проблема в упаковке.
  Пришлите сообщение из консоли и файл `logs\holocyt.log`.
- **Не работает и из исходников.** Проблема в зависимостях или в самой
  программе. Пришлите вывод `SELF_CHECK_WINDOWS.bat`.

Это различение важно: не надо чинить алгоритм, если сломалась упаковка.

### Антивирус блокирует

Собранное приложение не упаковано упаковщиком и не содержит
самораспаковывающихся модулей, но Windows Defender иногда всё равно
реагирует на свежесобранные исполняемые файлы. Добавьте папку в
исключения либо работайте из исходников.

### Кириллица выводится неразборчиво

Сообщите об этом. На работу расчёта и на содержимое PDF это не влияет:
отчёт формируется отдельно от консоли.

# Что получится

```
dist\
└── ГОЛОЦИТ\
    ├── ГОЛОЦИТ.exe          запуск
    ├── HOLOCYT.exe          он же, служебное имя
    ├── _internal\           библиотеки и ресурсы
    ├── models\              обученные модели
    ├── demo_data\           демонстрационный эксперимент
    ├── docs\                документация
    ├── out\                 сюда попадают отчёты и таблицы
    └── logs\                журнал работы
```

Папку можно копировать целиком на другие машины: Python на них уже
не понадобится.

# Почему папка, а не один файл

Один самораспаковывающийся файл выглядит аккуратнее, но при каждом
запуске распаковывает себя во временный каталог. Это медленнее,
чаще вызывает срабатывание антивируса и хуже диагностируется.
Для прибора, который показывают заказчику, надёжность важнее.
