# 1. Назначение

ГОЛОЦИТ читает эксперименты штатного программного обеспечения
микроскопа HoloMonitor M4 (Hstudio), находит объекты на картах сдвига
фазы, вычисляет их геометрию и оптические характеристики и формирует
отчёт.

Программа работает **рядом** со штатным ПО, ничего в нём не меняет
и его запуска не требует. Микроскоп для работы не нужен: анализируются
уже снятые данные.

Исследовательское программное обеспечение. Не является медицинским
изделием и не предназначено для постановки диагноза.

# 2. Системные требования

| | |
|---|---|
| Операционная система | Windows 10 или 11, 64 бита |
| Свободное место | 700 МБ |
| Оперативная память | 4 ГБ, рекомендуется 8 ГБ |
| Права администратора | не нужны |
| Доступ в Интернет | не нужен |
| Видеокарта | не нужна, расчёт идёт на процессоре |

# 3. Поддерживаемые данные

Каталог эксперимента Hstudio:

```
<эксперимент>/
├── imagedb.xml
├── Database/
│   └── phidbdata.sdf        не читается, и не требуется
└── Storage/
    └── PhaseMatrixStorage/
        └── 0/0/0/1/*.fmx    карты сдвига фазы
```

Также распознаётся каталог выгрузки базы, содержащий
`DBTransferInfo.xml` — из него читается калибровка прибора.

### Что читается и что нет

- **`.fmx`** — карта сдвига фазы, версия 2017. Поддерживается.
- **`.bin`** — версия 2010. **Не поддерживается**: раскладка данных
  в файле не разобрана, и чтение даёт искажённое изображение. Такие
  файлы программа отклоняет с пояснением, а не выдаёт неверный результат.
- **`phidbdata.sdf`** — база Microsoft SQL Server Compact. Не читается
  и для работы не нужна: карты фазы лежат отдельными файлами.

# 4. Запуск

Запустите **ГОЛОЦИТ.exe**. Откроется окно консоли с адресом программы
и затем браузер. Консоль закрывать нельзя — пока она открыта,
программа работает.

Если браузер не открылся сам, скопируйте адрес из консоли
(вида `http://127.0.0.1:8765/`) и откройте вручную.

Если порт занят, программа сама возьмёт следующий свободный.

# 5. Загрузка эксперимента

Укажите путь к каталогу и нажмите «Открыть». Программа покажет:
название, число кадров, размер изображения, формат карты фазы,
диапазон сдвига фазы, найденные источники метаданных и состояние
калибровки.

Пути с русскими буквами и пробелами поддерживаются.

# 6. Калибровка

Калибровка — это четыре величины: размер пикселя в плоскости объекта,
длина волны лазера и показатели преломления клеток и среды.

**В самих картах фазы их нет.** Единственный источник в данных
прибора — файл `DBTransferInfo.xml` из выгрузки базы Hstudio.

Если файла нет, есть два пути:

- работать без калибровки. Программа посчитает всё, что от неё не
  зависит: число объектов, площадь в пикселях, сдвиг фазы, долю
  занятой площади кадра;
- ввести значения вручную. Они будут помечены как заданные
  оператором — и в интерфейсе, и в отчёте, и в метаданных.

**Программа никогда не подставляет калибровку молча.** Если её нет,
величин в микрометрах и пикограммах в результате не будет вовсе.

# 7. Анализ

Нажмите «Анализировать». Один кадр 1024×1024 обрабатывается около двух
секунд.

Ход работы:

1. выравнивание дрейфа фона;
2. поиск объектов обученным классификатором пикселей;
3. разделение слипшихся объектов методом водоразделов;
4. отсечение слабого сигнала и мелких обломков;
5. измерение параметров каждого объекта.

Повреждённый файл пропускается, остальные считаются. Число пропущенных
выводится в конце и записывается в метаданные.

Повторный анализ тех же данных на той же версии даёт тот же результат:
генератор случайных чисел зафиксирован.

# 8. Показатели

Показатели разделены на три категории, и категория указывается везде —
в интерфейсе, в заголовках CSV и в отчёте.

| категория | смысл | примеры |
|---|---|---|
| A | измерено из карты фазы, калибровка не нужна | площадь в пикселях, сдвиг фазы, число объектов |
| B | требует калибровки прибора | площадь в мкм², оптическая толщина и объём, сухая масса |
| C | вычислено ГОЛОЦИТом | изрезанность, шероховатость, текстура, состояние объекта |

### Важно о названиях

Названия показателей категории C **не повторяют** номенклатуру Hstudio
там, где определения расходятся. Например, наша «изрезанность контура»
не равна параметру Irregularity штатного ПО: на площади 572 мкм² и
периметре 86,1 мкм из реальной выгрузки Hstudio сообщает 0,097, а наша
формула даёт 0,015. Сравнивать эти числа напрямую нельзя.

Полное сопоставление приведено в отчёте PDF, страница «Происхождение
величин».

# 9. Экспорт

**CSV** — по строке на каждый найденный объект. Колонки названы
по-русски, с единицами и пометкой категории. Сохраняются технический
номер кадра и номер объекта — по ним результат воспроизводится.

Рядом создаётся файл метаданных в формате JSON: версия программы, путь
к данным, калибровка с указанием происхождения каждой величины,
настройки анализа, список пропущенных файлов.

**PDF** — отчёт на четырёх страницах: титул с состоянием калибровки,
сводка с графиками, представительные кадры с разметкой, происхождение
величин и ограничения.

Оба файла сохраняются в папку `out` рядом с программой.

# 10. Ошибки

| что видите | что делать |
|---|---|
| Каталог не распознан как эксперимент Hstudio | Проверьте, что внутри есть `imagedb.xml` и папка `Storage` |
| Найдены карты фазы версии 2010 | Этот формат не поддерживается, нужны файлы `.fmx` |
| Калибровка не найдена | Это не ошибка. Работайте без физических величин либо введите калибровку вручную |
| Нет прав на запись | Скопируйте программу в папку, куда можно писать, например в «Документы» |
| Обработано не все кадры | Часть файлов повреждена. Список в конце и в `logs/holocyt.log` |

Трассировки Python пользователю не показываются: полный текст ошибки
пишется в журнал.

# 11. Демонстрационный режим

Кнопка «Открыть демонстрационный эксперимент» загружает восемь
настоящих кадров HoloMonitor M4 из опыта по заживлению раны
(съёмка 29.08.2017, планшет IBIDI µ-Plate 24 well with Culture Inserts).

Это **не синтетические данные**. Кадры скопированы побайтно и
отобраны так, чтобы покрыть весь диапазон заполненности поля — от
редкой культуры с видимой царапиной до плотного монослоя.

Калибровки в них нет, и программа это честно показывает.

# 12. Ограничения

- Разметка выполняется автоматически и оператором не проверяется.
  На плотных кадрах встречается дробление клетки и слияние соседних.
- Порог отсечения слабого сигнала подобран по одному эксперименту
  и универсальным не является. Меняется в `config/defaults.yaml`.
- Порядок кадров во времени в данных эксперимента не восстанавливается,
  поэтому графики подписаны «по порядку файлов», а не по времени.
- Классификация состояния объекта требует калибровки и обучена на
  модельных данных. Для конкретной клеточной линии её нужно дообучить.
- Числовая сверка показателей с Hstudio на одних и тех же клетках не
  проводилась.

Полный список — в файле `KNOWN_LIMITATIONS.md`.

# 13. Диагностика

**Журнал.** `logs/holocyt.log` — версия, путь к данным, калибровка,
пропущенные файлы, предупреждения, ошибки с полной трассировкой.

**Самодиагностика.** `SELF_CHECK_WINDOWS.bat` проверяет пятнадцать
условий работоспособности и печатает отчёт с пометкой PASS или FAIL
по каждому.

**Запуск из исходников.** `RUN_WINDOWS_SOURCE.bat` запускает программу
минуя сборку. Если из исходников работает, а собранное приложение нет —
причина в упаковке, а не в программе.
