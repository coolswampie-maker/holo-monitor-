# Базовое состояние перед подготовкой релиза

| | |
|---|---|
| Коммит baseline | `4b41568` |
| Коммит релиза | `e59fd5a` |

| Дата фиксации | 20.09.2026 |
| Версия | 1.0.0-rc1 |

## Что работало на момент фиксации

- Импорт эксперимента Hstudio из каталога с `imagedb.xml` и `Storage/`
- Чтение карт фазы `.fmx` (версия 2017), 1024×1024 float32, доли длины волны
- Разбор калибровки из `DBTransferInfo.xml`
- Разделение показателей на категории A / B / C
- Отказ вычислять физические величины без калибровки
- Сегментация обученным попиксельным классификатором с разделением слипшихся
- Отсечение слабого сигнала (порог 0,04 длины волны)
- Отчёт PDF на 4 страницы, выгрузка CSV
- Веб-интерфейс из пяти шагов, демонстрационный режим на реальных данных

## Известные ограничения на момент фиксации

- Формат `.bin` (версия 2010) декодировался неверно, но программа этого
  не замечала и отдавала искажённые данные
- Порог 0,04 подобран по одному эксперименту
- Порядок кадров во времени не восстанавливается
- База `phidbdata.sdf` не читается без Windows

## Реальные наборы данных
