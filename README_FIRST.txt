ГОЛОЦИТ 1.0.0 — комплект для переноса на Windows
=====================================================

ЧТО ЭТО

Исходный комплект программы ГОЛОЦИТ, подготовленный на macOS.
Здесь есть всё, что нужно, чтобы на Windows собрать автономное
приложение и проверить его.


С ЧЕГО НАЧАТЬ

1. Прочитайте docs/Windows_Build_Guide_RU.pdf — там подробно.
2. Установите Python 3.11 x64 с python.org
   (обязательно отметьте "Add python.exe to PATH").
3. Запустите build/BUILD_WINDOWS.bat
4. Запустите diagnostics/SELF_CHECK_WINDOWS.bat
5. Откройте папку dist и запустите приложение.

Если собирать не хочется или сборка не удалась — программу можно
запустить прямо из исходников: build/RUN_WINDOWS_SOURCE.bat


ЧТО ГДЕ

  app/           исходный код программы
  demo/          настоящий демонстрационный эксперимент M4 (8 кадров)
  docs/          руководства в PDF
  build/         сборка автономной версии
  diagnostics/   самодиагностика
  requirements/  списки зависимостей с точными версиями
  tests/         регрессионные проверки

  VERSION.txt              версия
  RELEASE_NOTES.md         что вошло в эту версию
  KNOWN_LIMITATIONS.md     ограничения продукта, только реальные
  WINDOWS_ACCEPTANCE.md    список приёмки, заполнить на Windows
  THIRD_PARTY_LICENSES.txt лицензии используемых библиотек
  CHECKSUMS.sha256         контрольные суммы для проверки после переноса


ВАЖНО

Всё, что требует настоящей Windows, НЕ ПРОВЕРЕНО: подготовка велась
на macOS. Список непроверенного — в конце WINDOWS_ACCEPTANCE.md.

Программа работает полностью локально. Доступ в Интернет нужен только
на время сборки, чтобы скачать зависимости.
