# Отложено

Сюда попадает всё, что кажется полезным, но выходит за рамки текущего
этапа. Реализация — только после приёмки на Windows.

## Разбор форматов

- **Формат карты фазы `.bin` (2010).** Раскладка в памяти не разобрана:
  строки чередуются с периодом 3, но ни одна из проверенных схем
  расшивки не даёт изотропного изображения. Блокирует набор MCF-10A —
  единственный с полной калибровкой.
- **Чтение `phidbdata.sdf`.** Microsoft SQL Server Compact 4.0. Дало бы
  соответствие «файл → номер съёмки», а с ним — настоящую временную ось.
- **Полное извлечение установщика Hstudio.** Контейнер `ISSetupStream`,
  энтропия 7,997 из 8,0.

## Анализ

- **Прослеживание клеток и родословные.** Требует известного порядка
  кадров во времени.
- **Анализ зарастания раны.** Площадь раны измеряется корректно уже
  сейчас; не хватает только порядка кадров, чтобы считать процент
  зарастания.
- **Дообучение классификатора состояния на реальной линии.** Нужна
  разметка от специалиста либо таймлапс с интервалом 5–10 минут, где
  деление клетки видно напрямую.
- **Адаптивный порог отсечения слабого сигнала.** Реализован, но по
  умолчанию выключен: на плотной культуре чистого фона для оценки не
  остаётся, разброс порога по кадрам 0,017…0,090.

## Продукт

- Пакетная обработка нескольких экспериментов подряд
- Сравнение групп внутри одного эксперимента
- Сохранение и повторное применение профиля калибровки прибора
- Экспорт размеченных масок для внешних программ
