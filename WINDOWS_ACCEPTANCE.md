Заполняется на настоящей машине с Windows. До этого ни один пункт
не считается пройденным.

Отмечайте: `[x]` — работает, `[!]` — не работает, `[-]` — не проверялось.

> **Заполнено 2026-09-20.** Проверка выполнена на настоящей Windows, на
> настоящих кадрах HoloMonitor M4 из комплекта
> `HOLOCYT_WINDOWS_TRANSFER_1.0.0-rc1.zip`. Сквозной сценарий пройден
> на **собранном приложении**, а не из исходников.

## Прочее

```
[-] Программа работает при отключённой сети
[x] Журнал logs\holocyt.log создаётся и заполняется
[x] SELF_CHECK_WINDOWS.bat: 18 / 18 PASS

[x] Трассировок Python пользователю не показывается
```

Сеть не отключалась: сеанс без прав администратора, `Disable-NetAdapter`
недоступен. Косвенно: проверка «Работа без сети» проходит — в
интерфейсе нет ни одной внешней ссылки.

Самодиагностика даёт 18 / 18 PASS, 0 FAIL, 0 SKIP. Значение «15 / 15»
из прежней редакции было получено не на Windows: три проверки помечены
`windows_only`, вне Windows пропускаются, и знаменатель равен 15. На
Windows их 18.

Регрессионный набор: 18 проверок, 16 выполнено, 16 PASS, 0 FAIL,
2 SKIP. Пропущены «Отказ от неподдержанного формата .bin» и «Импорт
калибровки из DBTransferInfo.xml» — в комплекте нет набора MCF-10A, на
котором они держатся. Пропуск не засчитывается прохождением.

Windows Defender включён, защита в реальном времени активна. Отдельное
сканирование готовой сборки: обнаружений 0, карантина нет. Исключения
Defender не добавлялись.

Трассировок Python пользователю не показывается ни в одном из
проверенных сценариев, включая повреждённый кадр и неверную папку.

## Если что-то не работает

Определите, где сломалось, — это разные проблемы и чинятся по-разному:

| симптом | скорее всего |
|---|---|
| `BUILD_WINDOWS.bat` падает на установке зависимостей | сеть или прокси |
| PyInstaller отработал, приложение не стартует | упаковка |
| `RUN_WINDOWS_SOURCE.bat` тоже не работает | зависимости или программа |
| Приложение стартует, браузер не открывается | браузер, адрес есть в консоли |
| Ошибка при чтении данных | данные или программа |
| Ошибка «не найдена библиотека DLL» | отсутствуют компоненты Visual C++ |

К отчёту приложите `logs\holocyt.log` и вывод
`SELF_CHECK_WINDOWS.bat`.
