## Прочее

```
[-] Программа работает при отключённой сети
[x] Журнал logs\holocyt.log создаётся и заполняется
[!] SELF_CHECK_WINDOWS.bat: 15 / 15 PASS
[x] Windows Defender не блокирует
[x] Трассировок Python пользователю не показывается   (после исправления)
```

Сеть на машине не отключалась. Косвенно: проверка «Работа без сети»
проходит — в интерфейсе нет ни одной внешней ссылки.

Самодиагностика даёт **12 / 18 PASS**, а не 15 / 15. Значение 15 / 15
достижимо только не на Windows: три проверки помечены `windows_only`,
вне Windows пропускаются, и знаменатель равен 15. На Windows они
выполняются. В исходном виде все три были заглушками
`raise NotImplementedError` и всегда падали, то есть 15 / 15 на Windows
недостижимо в принципе. После реализации этих проверок они проходят;
оставшиеся 6 отказов — только отсутствие `demo_data`. С данными
ожидается 18 / 18.

Windows Defender включён (защита в реальном времени активна), сборку не
блокировал и ничего не поместил в карантин.

Трассировка Python пользователю не показывается **после** исправления
паузы «Нажмите Enter» в `run.py`: при запуске без консоли поверх
понятного сообщения печатался `EOFError`.

## Если что-то не работает

Определите, где сломалось, — это разные проблемы и чинятся по-разному:

| симптом | скорее всего |
|---|---|
| `BUILD_WINDOWS.bat` падает на установке зависимостей | сеть или прокси |
| PyInstaller отработал, приложение не стартует | упаковка |
| `RUN_WINDOWS_SOURCE.bat` тоже не работает | зависимости или программа |
| Приложение стартует, браузер не открывается | браузер, адрес есть в консоли |
| Ошибка при чтении данных | данные или программа |
| Ошибка «не найдена библиотека DLL» | отсутствуют компоненты Visual C++ |

К отчёту приложите `logs\holocyt.log` и вывод
`SELF_CHECK_WINDOWS.bat`.
