# Ограничения ГОЛОЦИТ 1.0.0-rc1

Только то, что установлено проверкой. Предположений здесь нет.

## Данные

**Поддерживается один формат карты фазы.** `.fmx` (версия 2017),
проверен на 56 настоящих кадрах HoloMonitor M4.

**Формат `.bin` (версия 2010) не поддерживается.** Его раскладка в
памяти не разобрана: декодирование даёт изображение с анизотропией
соседних разностей 2,15 против 1,00 у корректного кадра. Программа
такие файлы отклоняет с пояснением, а не отдаёт искажённые данные.

**База `phidbdata.sdf` не читается.** Microsoft SQL Server Compact 4.0,
без Windows и .NET недоступна. На работу это не влияет: карты фазы
лежат отдельными файлами.

## Калибровка

**В картах фазы калибровки нет.** Проверено по всем 56 файлам. Её
единственный источник в данных прибора — `DBTransferInfo.xml` из
выгрузки базы. Если его нет, калибровку вводит оператор, и она
помечается как заданная пользователем, а не измеренная.

**Без калибровки физические величины не вычисляются вовсе** — ни
микрометры, ни кубические микрометры, ни пикограммы. Это не сбой,
а намеренное поведение.

## Время

**Порядок кадров во времени не восстанавливается.** Имена файлов не
соответствуют порядку съёмки: изображения похожи с периодом 8
(коэффициент корреляции 0,69 против 0,29 у соседних), а соответствие
«файл → номер съёмки» из базы извлечь не удалось. Поэтому графики
подписаны «по порядку файлов», а анализ зарастания раны не включён.

## Сегментация

**Порог отсечения слабого сигнала 0,04 длины волны подобран по одному
эксперименту** и универсальным порогом для M4 не является. На другой
клеточной линии может потребовать правки — задаётся в
`config/defaults.yaml`.

**Разметка не проверяется оператором.** Автоматический результат может
дробить клетку на части, сливать соседние и отбрасывать
слабоконтрастные. Визуальная проверка на реальных данных описана в
`VALIDATION_REAL_DATA.md`.

## Показатели

**Названия показателей категории C не повторяют номенклатуру Hstudio**
там, где определения расходятся. Проверено численно: их
`Irregularity = 0,097`, наша формула на тех же числах даёт 0,015.

**Числовая сверка с Hstudio на одних и тех же клетках не проводилась**:
к найденной выгрузке A549 не приложены изображения.

**Классификация состояния клетки требует калибровки** и обучена на
модельных данных. Для конкретной клеточной линии её нужно дообучить.

## Назначение

Исследовательское программное обеспечение. Не является медицинским
изделием и не предназначено для постановки диагноза.
