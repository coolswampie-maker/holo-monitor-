# ГОЛОЦИТ — установка на рабочую станцию

Версия для Windows поставляется **переносимой папкой**. Устанавливать
нечего: программа не пишет в системные каталоги и в реестр, не требует
прав администратора и не обращается в сеть.

---

## Требования

| | |
|---|---|
| Операционная система | Windows 10 или 11, 64 бита |
| Свободное место | 600 МБ (папка 334 МБ плюс место под результаты) |
| Оперативная память | 4 ГБ, рекомендуется 8 ГБ |
| Права администратора | **не нужны** |
| Доступ в интернет | **не нужен** |
| Предустановленный Python | **не нужен** — входит в поставку |
| Видеокарта | не нужна, расчёт идёт на процессоре |

Программа работает **рядом** со штатным ПО микроскопа (Hstudio),
ничего в нём не меняет и не требует его остановки.

---

## Порядок установки

**1.** Скопировать папку `ГОЛОЦИТ-windows` на рабочую станцию — например,
в `C:\ГОЛОЦИТ`. Можно запускать и прямо с флешки, но с локального диска
работает заметно быстрее.

> Папку нужно скопировать **целиком**. Отдельные файлы по одному
> перенести нельзя.

**2.** Запустить **`Проверка.bat`** (двойным щелчком).

Программа проверит десять условий работоспособности и напечатает отчёт.
Ожидаемый результат:

```
  Все проверки пройдены. Программа готова к работе.
```

Если какая-то строка отмечена `ОТКАЗ`, под ней указана причина. Этот
экран и нужно показать разработчику — по нему сразу видно, что не так.

**3.** Запустить **`ГОЛОЦИТ.bat`**.

Откроется браузер со страницей программы. Путь к демонстрационному
эксперименту уже подставлен — достаточно нажать «Анализировать».

Чтобы завершить работу, закройте чёрное окно консоли.

---

## Что в папке

| файл | назначение |
|---|---|
| `ГОЛОЦИТ.bat` | основной запуск, открывает интерфейс в браузере |
| `Проверка.bat` | самопроверка рабочего места |
| `Командная строка.bat` | запуск из командной строки, для пакетной обработки |
| `python\` | встраиваемый Python, не связан с системным |
| `lib\` | библиотеки расчёта |
| `models\` | обученные модели |
| `demo_data\` | демонстрационный эксперимент |
| `out\` | сюда складываются протоколы и таблицы |

---

## Для службы информационных технологий

Что программа делает:

- читает файлы изображений из указанного пользователем каталога;
- пишет результаты **только** в подкаталог `out\` внутри своей папки;
- поднимает веб-сервер на `127.0.0.1`, порт `8765` — **петлевой интерфейс,
  наружу не слушает**, соединений не инициирует.

Чего программа не делает:

- не пишет в `Program Files`, `Windows`, `AppData` и реестр;
- не устанавливает служб и заданий планировщика;
- не требует прав администратора;
- **не обращается в интернет** — ни при установке, ни при работе.

Состав поставки: интерпретатор CPython 3.11.9 (Python Software
Foundation License) и открытые библиотеки численного анализа —
NumPy, SciPy, scikit-image, scikit-learn, Matplotlib, Pillow, tifffile
(лицензии BSD и MIT). Прикладной код разработан самостоятельно.

Если требуется другой порт:

```
Командная строка.bat
```
— и далее запуск вида `python\python.exe run.py --port 9000`.

## Если что-то не работает

**Браузер не открылся.** Программа при запуске печатает адрес вида
`http://127.0.0.1:8765/`. Откройте его вручную.

**Порт занят.** Запустите с другим портом:
`python\python.exe run.py --port 8800`.

**Антивирус блокирует запуск.** В поставке нет упакованных исполняемых
файлов — только подписанный `python.exe` от Python Software Foundation
и обычные файлы `.pyd`. Ложное срабатывание снимается добавлением папки
в исключения.

**Кириллица выводится неразборчиво.** Сообщите об этом: значит,
переключение консоли в UTF-8 на вашей сборке Windows не сработало.
На работу расчёта и на PDF-протоколы это не влияет.

**Отказ на пункте «Совпадение версий с моделями».** Версии библиотек
разошлись с теми, которыми обучены модели. Так бывает, если папку
собирали и дополняли по частям. Нужна целая поставка.

---

## Обновление

Заменить папку целиком на новую. Результаты из `out\` перед этим
скопировать в другое место — они не переносятся автоматически.
