# Проверка на реальных данных

Только наблюдения и измерения. Никаких показателей точности,
посчитанных на синтетике.

## Наборы

| набор | кадров | формат | калибровка | статус |
|---|---|---|---|---|
| Example woundhealing | 56 | `.fmx` 1024×1024 | нет | **проверен полностью** |
| MCF-10A time-lapse | 100 | `.bin` 960×768 | полная | **не читается**, см. ниже |

### Почему MCF-10A не проверен

Формат `.bin` декодируется неверно. Мера — анизотропия средних
абсолютных разностей соседних пикселей: у корректного кадра она равна
1,00, у `.bin` при любой из проверенных раскладок — 2,15 и выше.
Изображение получается полосатым, клеток на нём нет.

Перебраны: смещения данных 8, 16, 24, 1024, 1040, 1048; ширины 240, 256,
320, 384, 480, 512, 640, 720, 768, 960, 1024, 1280, 1440, 2880; порядок
C и Fortran; расшивка строк и столбцов с периодом 3; чтение тремя
плоскостями. Лучший результат — анизотропия 1,05 при шероховатости
0,053 против 0,015 у эталона, то есть шум, а не изображение.

Программа такие файлы **отклоняет с пояснением**. Калибровка из
`DBTransferInfo.xml` того же каталога при этом читается и может быть
применена к другому эксперименту.

диапазон заполненности от 28 % до 62 %.

|---|---|---|---|
| 1587 | 28 % | 105 | 192 |

| 1626 | 62 % | 277 | 244 |

### Что проверялось и что найдено

**Фон принимается за клетки — БЫЛО, исправлено.** В кадрах с царапиной
разметка покрывала контурами пустую область. Распределение средней фазы
объектов там двугорбое: мусор около 0,025 длины волны, настоящие клетки
от 0,086. Введено отсечение по 0,04. После исправления в области
царапины контуров нет — видно на `docs/ablation_порог.png`.

**Царапина принимается за клетки — НЕТ.** После исправления пустая
область чистая на всех проверенных кадрах.

**Одна клетка дробится на несколько — редко.** На плотных кадрах
встречаются клетки, рассечённые прямой линией водораздела. Доля на глаз
единицы процентов. Численно не измерено: эталонной разметки нет.

**Несколько клеток сливаются — встречается на самых плотных кадрах**
(покрытие свыше 60 %), где границы между соседями неразличимы и на
исходном изображении.

**Обломки — отсекаются** порогом минимальной площади 500 пикселей
и порогом слабого сигнала.

**Краевые объекты — отбрасываются** намеренно, как и в штатном ПО.

**Чрезмерное отсечение слабоконтрастных клеток — не наблюдается.** При
включении фильтра в плотных кадрах пропадает 1 объект из 278.

## Проверка порога отсечения

Изображения «до и после»: `docs/ablation_порог.png`.

| кадр | покрытие | без фильтра | с порогом 0,04 | удалено |
|---|---|---|---|---|
| 1587 | 28 % | 178 | 105 | 73 |
| 1593 | 37 % | 222 | 147 | 75 |
| 1626 | 62 % | 278 | 277 | 1 |

Удаляются именно мелкие объекты в пустой области: медианная площадь
в редких кадрах после фильтра выросла со 141 до 192–213 мкм², то есть
сравнялась с плотными кадрами.

### Попытка сделать порог адаптивным

Постоянное число, подобранное по одному набору, — слабое место.
Проверены три способа вывести порог из самого кадра:

| способ оценки шума | порог по кадрам |
|---|---|
| медианное абсолютное отклонение по нижним 40 % | 0,061…0,112 |
| по нижнему хвосту распределения пикселей | 0,112…0,198 |
| по локальным средним вне переднего плана | 0,017…0,090 |

Нужный диапазон — 0,04…0,06. Ни один способ в него не укладывается:
фон в этих снимках не гауссов шум, а структура, и в плотной культуре
чистого фона для оценки почти не остаётся (0,1 % площади кадра).

**Решение:** по умолчанию оставлен постоянный порог 0,04, честно
помеченный как подобранный по одному эксперименту. Адаптивный режим
реализован и доступен через `config/defaults.yaml` как
экспериментальный. Фильтр можно отключить целиком (`mode: off`).

Проверить перенос порога на второй набор не удалось: MCF-10A не
читается.

## Физика на реальных данных

При калибровке, введённой оператором (пиксель 0,336 мкм, длина волны
0,633 мкм, показатели преломления 1,38 и 1,34):

| показатель | значение | ожидаемое |
|---|---|---|
| медианная площадь объекта | 237 мкм² | 100–600 для эпителия |
| медианная оптическая толщина | 2,18 мкм | 1–5 для распластанной клетки |
| медианный оптический объём | 547 мкм³ | — |
| медианная сухая масса | 121 пг | 100–500 для клетки млекопитающего |

Значения правдоподобны. Это не валидация: эталонных измерений тех же
клеток нет, а калибровка введена вручную.
