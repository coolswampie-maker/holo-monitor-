# ГОЛОЦИТ 1.0.0

Первая рабочая версия. Собрана и проверена на Windows на настоящих
кадрах HoloMonitor M4; кандидаты rc1 и rc2 отличались от неё только
исправлениями переноса на Windows, разобранными ниже.

## Что входит

- **Импорт карт фазы `.fmx`** штатного ПО микроскопа HoloMonitor M4
  (Hstudio), с метаданными из `imagedb.xml` и калибровкой из
  `DBTransferInfo.xml`, когда он есть. Читается и каталог эксперимента,
  и папка с файлами россыпью.
- **Поиск и обмер клеточных объектов**: обученный классификатор
  пикселей, разделение слипшихся методом водоразделов.
- **Работа с калибровкой**: при полной калибровке считаются площадь в
  мкм², оптический объём и сухая масса.
- **Работа без калибровки**: физические величины не вычисляются вовсе,
  остаются счёт объектов, геометрия в пикселях и статистика сдвига
  фазы. Программа сообщает об этом прямо в интерфейсе.
- **Происхождение каждого показателя** помечено категорией: A —
  измерено из карты фазы, B — требует калибровки прибора, C —
  вычислено ГОЛОЦИТом. Пометки попадают и в выгрузку, и в отчёт.
- **Отчёт PDF** с кириллицей, графиками и кадрами с разметкой.
- **Выгрузка CSV** в UTF-8 с BOM и разделителем «;» — открывается в
  Excel без настройки, плюс файл метаданных в JSON.
- **Демонстрационный эксперимент** — настоящие 8 кадров M4, входит в
  поставку.
- **Всё локально**: программа работает на одном компьютере, наружу
  ничего не передаёт, интернет не нужен.
- **Автономная сборка для Windows**: папка с исполняемым файлом,
  Python и библиотеки внутри, отдельная установка не требуется.

## Ограничения

Перечислены в `KNOWN_LIMITATIONS.md`. Коротко: формат `.bin` не
читается; временной порядок кадров в имеющихся данных не
восстанавливается; порог отсечения слабого сигнала подобран на одном
реальном эксперименте; программа не является медицинским изделием.

# ГОЛОЦИТ 1.0.0-rc2

Приёмка на Windows. Функциональность не менялась: rc1 не запускался
после сборки, и это исправлено.

## Что исправлено против rc1

**Сборка не запускалась.** PyInstaller не клал в неё два модуля,
которые подгружаются из скомпилированного кода и потому не видны при
разборе исходного текста: `numpy._core._exceptions` и
`scipy._cyutility`. Из исходников программа работала, собранная падала
при старте. Штатные hook-файлы PyInstaller 6.11.1 старше numpy 2.4 и
scipy 1.17 и об этих зависимостях не знают.

**Проверка сборки пропускала неработоспособную сборку.** Она
ограничивалась `--version`, а этот вызов печатает версию и завершает
работу до импорта numpy. Теперь проверка поднимает приложение целиком
и ждёт ответа интерфейса.

**Второй экземпляр вставал на порт первого.** Занятость порта
проверялась сокетом с `SO_REUSEADDR`; на Windows эта опция разрешает
двум сокетам занять один адрес, поэтому порт всегда объявлялся
свободным. Второй запуск жил, но не отвечал.

**Результаты уходили внутрь сборки.** Каталог выгрузки вычислялся от
каталога модуля и в собранном виде указывал на служебный `_internal`,
тогда как `out` рядом с программой оставался пустым.

**Повреждённый кадр обрывал анализ в интерфейсе.** Показ хода работы
обращался к результату кадра без проверки, хотя для непрочитанного
кадра он равен `None`. Остальные кадры при этом уже были посчитаны.

**Посторонний каталог принимался за эксперимент.** Расширение `.bin`
само по себе считалось признаком выгрузки Hstudio, поэтому, например,
`C:\Windows\System32` проходил распознавание, а запрос к интерфейсу
заканчивался HTTP 500 без пояснения. Поддержка `.bin` не добавлена:
формат по-прежнему отклоняется с пояснением.

**Три проверки самодиагностики были заглушками.** Помеченные
`windows_only`, вне Windows они пропускались, а на Windows всегда
падали. Реализованы: запуск собранного приложения, загрузка
C-расширений, наличие браузера.

**Пропущенная проверка засчитывалась пройденной.** Самодиагностика и
регрессионный набор теперь различают PASS, FAIL и SKIP, а итог
показывает, сколько проверок действительно выполнялось.

**Мелкое.** Адрес интерфейса не сбрасывался из буфера при
перенаправлении вывода. Пауза «Нажмите Enter» роняла `EOFError` при
запуске без консоли. Из описания сборки убран несуществующий
`scipy.special._cdflib`.

# ГОЛОЦИТ 1.0.0-rc1

Первая версия, пригодная к переносу на рабочую станцию и показу.

## Что умеет

- Читает эксперименты штатного ПО микроскопа HoloMonitor M4 (Hstudio):
  карты сдвига фазы `.fmx`, метаданные из `imagedb.xml`, калибровку
  из `DBTransferInfo.xml`
- Находит объекты обученным классификатором пикселей, разделяет
  слипшиеся методом водоразделов
- Вычисляет 45 показателей, разделённых на три категории по тому,
  откуда они берутся
- Формирует отчёт PDF и таблицу CSV с метаданными анализа
- Работает полностью локально, без доступа в сеть

## Главные решения этой версии

**Физические величины не вычисляются без калибровки.** Ни микрометры,
ни пикограммы. Подставить значение «по умолчанию» и выдать его за
измерение нельзя — в отчёте оно было бы неотличимо от настоящего.

**Названия показателей не заимствуют номенклатуру Hstudio** там, где
определения расходятся. Проверено численно на реальной выгрузке.

**Демонстрационный режим работает на настоящих данных M4**, а не на
синтетике. Восемь кадров из опыта по заживлению раны входят в поставку.

**Формат `.bin` отклоняется**, а не читается с искажениями.

## Что изменилось относительно предыдущего состояния

- Реестр показателей с категориями A / B / C и сопоставлением с Hstudio
- Объект калибровки со статусом каждой величины
- Центральная конфигурация, версия задаётся в одном месте
- Журнал работы, понятные сообщения об ошибках вместо трассировок
- Повреждённый кадр пропускается, остальные считаются
- Порт подбирается автоматически, если 8765 занят
- Отчёт PDF переработан в продуктовый вид
- CSV с русскими заголовками и файлом метаданных
- Регрессионный набор из 16 проверок, самодиагностика из 15

## Исправлено

- **Любой каталог распознавался как эксперимент.** Причина:
  `any(path.rglob(...))` всегда истинно, потому что `rglob` возвращает
  генератор. Найдено регрессионным тестом.
- **Фон в области царапины принимался за клетки.** Введено отсечение
  слабого сигнала.
- **Формат `.bin` читался с искажениями** и выдавался за данные.
- **Размер пикселя по умолчанию был неверен** в 1,6 раза. Теперь по
  умолчанию его нет вовсе.

## Не вошло

Прослеживание клеток, анализ зарастания раны, расчёт IC50, чтение базы
`phidbdata.sdf`, поддержка формата `.bin`. Причины — в `FUTURE.md`.

## Проверено и не проверено

Проверено на macOS: 16 регрессионных тестов, 15 пунктов
самодиагностики, два реальных набора данных.

**Не проверено ничего, что требует Windows.** Полный список — в конце
`WINDOWS_ACCEPTANCE.md`.
